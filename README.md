Setup
Registrati su AccuWeather Developer e ottieni la tua API Key.

Crea un file chiamato key.dart nella directory del progetto.

All'interno di key.dart, aggiungi la seguente riga:

dart
Copia
Modifica
const String apiKey = 'la_tua_api_key';
⚠️ Non condividere pubblicamente la tua API Key.

⚠️ Limitazioni
L’API gratuita di AccuWeather ha delle limitazioni d’uso (es. numero massimo di richieste).

Se, dopo un po’ di tempo, l'app smette di funzionare, molto probabilmente hai superato il limite gratuito.

In tal caso, puoi:

Richiedere una nuova API gratuita con un lo stesso account.

Oppure passare a un piano a pagamento.
